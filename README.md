# 叮叮记账

一款采用“柔和奶油”视觉风格的微信原生记账小程序。支持日常收支、统计、预算、贷款和欠款管理；未登录数据保存在本机，配置微信云开发后可登录并自动同步。

## 本地预览

1. 安装微信开发者工具。
2. 选择“导入项目”，目录指向本仓库根目录。
3. 暂无 AppID 时使用测试号；工程默认 `touristappid` 和本地存储模式。
4. 编译后从底部导航进入首页、明细、记账、统计和我的。

初次启动会生成与设计稿一致的示例账本。手动记账、删除账目、预算统计、贷款还款和欠款还款均可直接操作。

## 自动检查

要求 Node.js 22 或更高版本：

```powershell
npm test
npm run check
```

## 云同步

当前云能力默认关闭，不影响本地使用。取得小程序 AppID 和云环境 ID 后，按照 [云开发配置](docs/cloud-setup.md) 填写配置并部署云函数。

## 目录

- `pages/`：10 个小程序页面
- `components/`：柔和奶油公共组件
- `domain/`：金额、统计、预算、贷款、欠款和同步规则
- `services/`：本地仓储、业务服务和同步服务
- `cloudfunctions/`：身份识别和增量同步
- `tests/`：可重复执行的业务与工程测试
