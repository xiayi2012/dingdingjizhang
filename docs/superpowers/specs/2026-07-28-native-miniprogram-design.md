# 叮叮记账微信原生小程序开发规格

## 1. 目标与范围

本阶段将已确认的“柔和奶油”高保真设计实现为可导入微信开发者工具的原生 JavaScript 小程序。第一版面向个人用户，支持未登录本地使用，并预置微信登录、云数据库和自动同步架构。

由于当前尚无微信小程序 AppID 和云开发环境 ID，工程使用可替换配置。未配置云环境时，小程序必须完整运行在本地模式，不得因云能力缺失阻断记账。

本阶段实现：

- 首页、明细、手动记账、统计、我的
- 贷款列表、贷款详情
- 欠款列表、欠款详情
- 预算设置
- 本地数据增删改查和页面间实时联动
- 微信登录入口、首次上传、增量同步和冲突处理架构
- 云函数及云数据库集合初始化说明

聊天记账和语音记账只实现切换入口与说明状态，不实现自然语言解析、录音或语音识别。

## 2. 技术方案

### 2.1 技术栈

- 微信原生小程序
- JavaScript
- WXML、WXSS
- 微信本地存储
- 微信云开发、云函数、云数据库
- Node.js 内置测试运行器，用于纯业务模块自动测试

### 2.2 分层结构

工程分为四层：

1. 页面层：展示数据、响应用户操作，不直接访问存储。
2. 业务层：处理金额、统计、预算、贷款、欠款等领域规则。
3. 数据层：通过统一仓储接口访问本地存储，并在登录后触发云同步。
4. 云函数层：识别微信用户、接收批量变更、返回增量数据并完成冲突合并。

页面不得直接调用 `wx.setStorageSync`、`wx.cloud.database()` 或云函数。所有数据操作必须通过业务服务和仓储完成。

## 3. 视觉系统

最终界面使用“柔和奶油”色板：

- 主色：`#F1D37A`
- 薄荷辅助：`#7FAE9A`
- 背景：`#FFFAEC`
- 卡片：`#FFFDF8`
- 正文：`#2C3833`
- 收入：`#4D806B`
- 提醒：`#D9786C`

黄色面积约占 10%–15%，薄荷绿约占 8%–12%，背景和卡片等中性色至少占 70%。黄色按钮统一使用深色文字。界面使用圆润但克制的卡片、清晰的数据层级和轻量小铃铛品牌元素。

所有页面采用原生组件重新排版，不把设计图作为页面背景或整屏切图。公共组件统一控制标题栏、金额卡片、进度条、状态标签、空状态和五项底部导航。

## 4. 页面与交互

### 4.1 首页

展示今日支出、今日笔数、较昨日变化、三种记账入口、本月预算、最近记录、贷款提醒和欠款提醒。中央“记账”及手动记账入口直接打开手动记账页。

### 4.2 明细

按日期分组展示收入与支出，支持关键词搜索，并支持收支类型筛选。用户可进入编辑流程或二次确认后删除记录。

### 4.3 手动记账

支持收入与支出切换。金额、分类和账户必填；备注与日期可选。金额以元输入，保存时转换为整数分。保存成功后返回来源页面并刷新汇总。

聊天和语音标签切换后显示功能说明及“暂未开放识别”的明确状态，不创建伪识别结果。

### 4.4 统计

支持本周、本月和本年范围，展示收入、支出、结余、支出趋势、分类占比、分类排行和预算进度。无数据时展示首次记账引导，不渲染空图表。

### 4.5 我的

展示本地或云同步状态、微信登录入口，以及账本、账户、分类、预算、提醒、数据导出和关于入口。云环境未配置时，登录入口说明需先配置开发环境。

### 4.6 贷款

贷款列表展示剩余本金、下次还款日、每期金额和还款进度。详情页展示贷款字段、还款计划和最近还款记录。登记还款时可选择同步生成支出记录。

### 4.7 欠款

列表区分“别人欠我的”和“我欠别人的”，展示联系人、剩余金额、约定日期和状态。详情页展示初始金额、已还金额、剩余金额和分次还款时间线。登记还款时可选择同步生成收入或支出记录。

### 4.8 预算

支持月度总预算、餐饮、购物和交通等分类预算，以及 80% 和 100% 提醒开关。预算进度从实际账目计算。

## 5. 数据模型

金额统一使用整数分。日期使用 `YYYY-MM-DD`，时间使用 ISO 8601 字符串。

所有可同步实体包含：

- `id`：客户端生成的全局唯一标识
- `bookId`：所属账本
- `createdAt`：创建时间
- `updatedAt`：更新时间
- `syncStatus`：`local`、`pending` 或 `synced`
- `deleted`：同步删除标记

核心实体：

- `books`：账本及预留成员关系
- `transactions`：收入、支出和转账记录
- `accounts`：微信零钱、现金、银行卡等账户
- `categories`：收支分类
- `budgets`：月度总预算和分类预算
- `loans`：贷款资料
- `loanPayments`：贷款还款记录
- `debts`：借入与借出资料
- `debtPayments`：欠款分次还款记录
- `syncMeta`：设备同步游标与最近同步状态

## 6. 本地存储与云同步

### 6.1 未登录

所有操作先写入本地仓储。新增、修改和删除立即反映在界面中。页面明确显示“仅保存在本机”，并提示清除数据或更换设备可能造成数据丢失。

### 6.2 登录与首次上传

配置云环境后，用户点击微信登录：

1. 调用身份云函数获取当前用户标识。
2. 将本机尚未同步的数据批量上传。
3. 拉取云端当前账本数据。
4. 执行冲突合并并写回本地。
5. 保存同步游标，切换为自动同步状态。

首次上传失败时保留全部本地数据，并显示可重试状态。

### 6.3 增量同步

登录后的操作仍先写本地并标为 `pending`，再在后台推送。云端返回自上次游标之后的变更，本地合并成功后标为 `synced`。

同一实体在本地和云端均被修改时，保留 `updatedAt` 较新的版本。时间相同且内容不同时保留本地版本，并记录冲突提示。删除使用 `deleted: true` 的墓碑记录，避免旧设备恢复已删除数据。

### 6.4 未配置云环境

云能力由统一配置开关控制。AppID 或云环境 ID 未配置时：

- 小程序继续完整使用本地模式
- 不初始化云开发
- 不调用云函数
- 登录入口显示配置说明
- 不弹出影响日常使用的错误

## 7. 错误与空状态

- 保存失败：保留当前表单并显示原因和重试操作。
- 删除失败：保持原数据，不提前移除界面内容。
- 同步失败：继续使用本地数据，状态显示为“待同步”。
- 登录失败：保留本地模式，并允许再次尝试。
- 无账目：显示“记下第一笔”的入口。
- 无统计：显示记账引导，不展示空图表。
- 无贷款或欠款：显示用途说明和新增入口。
- 删除账目、贷款或欠款前必须二次确认。

## 8. 测试与验收

自动测试覆盖：

- 元与分的转换和格式化
- 收支、结余和分类汇总
- 周、月、年日期范围
- 总预算和分类预算进度
- 贷款还款后的剩余本金
- 欠款分次还款后的剩余金额和结清状态
- 本地数据迁移与默认数据初始化
- 同步队列、冲突合并和删除墓碑

视觉与交互验收：

- 微信开发者工具可直接导入工程
- 10 个页面均可进入且核心交互可运行
- 五项底部导航与中央记账入口一致
- 柔和奶油色板、深色按钮文字和小铃铛元素符合设计稿
- 页面数据由统一仓储提供，修改后相关汇总实时更新
- 云环境缺失时本地模式无阻断报错
- 常见手机宽度下无文字截断、遮挡或横向滚动
