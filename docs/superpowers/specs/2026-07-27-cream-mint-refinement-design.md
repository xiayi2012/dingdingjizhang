# 叮叮记账奶油薄荷配色微调说明

## 1. 目标

以用户选定的“奶油薄荷”为基础，生成原版与三套微调方案的并排对比稿，判断哪一套在年轻感、协调度和品牌辨识度之间最平衡。

## 2. 对比范围

对比稿共展示四套：

1. 原版奶油薄荷
2. 柔和奶油
3. 清爽薄荷
4. 品牌平衡

四套使用完全相同的首页组件、示例数据、小铃铛角色、卡片结构和排版，只改变颜色。

统一展示：

- 今日支出 `¥128.50`
- 手动记账、聊天记账、语音记账入口
- 本月预算 `¥6,000`
- 已用 `52%`
- 收入状态
- 三天后还款提醒
- “记一笔”按钮
- 小铃铛提醒角色

## 3. 配色定义

### 3.1 原版奶油薄荷

- 主色：`#F3CE63`
- 薄荷辅助：`#58A990`
- 背景：`#FFF9E9`
- 卡片：`#FFFFFF`
- 正文：`#273731`
- 收入：`#32846B`
- 提醒：`#E46A5D`

### 3.2 柔和奶油

- 说明：降低黄绿饱和度，温暖、治愈
- 主色：`#F1D37A`

- 背景：`#FFFAEC`
- 卡片：`#FFFDF8`

- 收入：`#4D806B`
- 提醒：`#D9786C`

### 3.3 清爽薄荷

- 说明：黄色更浅，绿色承担更多导航与数据强调
- 主色：`#F6D96B`
- 薄荷辅助：`#45A987`

- 提醒：`#E06D5F`

### 3.4 品牌平衡

- 说明：保留明快黄绿记忆点，通过比例降低色彩竞争

- 薄荷辅助：`#4E9B7F`
- 背景：`#FFF9E8`
- 卡片：`#FFFFFF`
- 正文：`#263631`
- 收入：`#3B7F69`
- 提醒：`#D96F62`

该方案为推荐方向。

## 4. 使用规则

- 黄色面积约占界面的 10%–15%，主要用于记账按钮、今日支出卡片和小铃铛主体
- 薄荷绿面积约占 8%–12%，主要用于预算进度、导航选中态、图标和收入信息
- 背景与白色卡片承担至少 70% 的面积
- 黄色按钮使用深色正文色，不使用白字
- 提醒色只用于临期、失败和超支状态
- 收入色只用于收入金额及其图标
- 小铃铛角色的主体使用主黄，帽扣或铃舌使用薄荷辅助色

## 5. 验收标准

- 四套方案的组件、文案、数据和排版一致
- 28 个 HEX 色值与本说明一致
- 所有黄色按钮使用深色文字
- 收入与提醒同时使用文字和颜色表达
- 小铃铛不遮挡金额、按钮或状态标签
- 四套方案的差异在同一屏幕上清晰可辨
- 输出 PNG 中名称、说明、主要文字和 HEX 清晰可读
